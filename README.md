# 🏋️‍♂️ FitSync – Your AI-Powered Fitness Companion

![FitSync Cover](https://github.com/user-attachments/assets/7b915076-d9cb-45ff-882e-879f9c353355)



> **Reimagine fitness tracking.**  
> FitSync is a full-stack, generative AI-powered fitness app that personalizes workouts, tracks calories, visualizes gym progress, and assists with AI-guided health advice. Built to motivate, organized to evolve.

---

## 💡 Why I Built This

During my fitness journey, I faced challenges tracking my gym attendance, calorie burns, and sticking to personalized diet plans. This lack of structure led to fatigue and inconsistency.

**FitSync** is my solution—leveraging **AI + Data + Design** to craft a **motivating, personalized fitness experience** that’s always within reach.

### 🧠 Why These Technologies?

| Technology    | Purpose                                                                 |
|---------------|-------------------------------------------------------------------------|
| **Next.js**   | Server-rendered React framework for fast, scalable web applications.    |
| **Radix UI**  | Accessible, unstyled components for crafting clean, responsive UIs.     |
| **Tailwind CSS** | Rapid, utility-first styling directly in markup.                     |
| **Node.js**   | Backend JavaScript runtime to handle server-side logic and API routes.  |
| **MongoDB**   | Flexible NoSQL database to store user profiles, workouts, and meals.    |
| **LangChain** | Connects AI models with custom logic for rich chatbot experiences.      |
| **Pinecone**  | Vector database to enable fast, relevant AI responses via embeddings.   |
| **Gemini AI** | Powers intelligent diet plans and Q&A through LLM capabilities.         |
| **Git**       | Version control for collaboration and code history.                     |

## 🎯 Project Goals

- ✅ Replace boring workout logs with an intelligent dashboard.
- ✅ Auto-generate diet plans based on workout type and user goals.
- ✅ Motivate users through visual progress.
- ✅ Integrate an AI trainer for real-time help & health tips.

---

## 🌟 Key Features

### 🧬 AI Training Assistant
Chat with your personal AI fitness coach for instant help—powered by Gemini + LangChain + Pinecone for fast, contextual replies.

### 🍽️ Personalized Diet Charts
Input your preferences, goals, and restrictions. Get a weekly adaptive plan powered by LLMs.

### 📊 Interactive Progress Tracking
Monitor calories burned, attendance, and training split trends using sleek analytics and charts.

### 🏃‍♂️ Cardio & Strength Workouts
Easily toggle between different workout modes and log duration or reps—gamify your fitness.

### 🎯 Adaptive Dashboard
Visual, responsive UI made with Tailwind and Radix for optimal experience across all screens.
